# Resona – เกมท่องเที่ยวฝึกพูด (prototype)

เกมฝึกพูดสำหรับผู้ป่วยพาร์กินสันตามหลัก LSVT LOUD (ไฟล์เดียว `public/index.html` = เกม v17)
- **ทริปใหม่ทุกครั้ง:** เซิร์ฟเวอร์สุ่มสถานที่จริง และคำ/ประโยคที่ให้พูดจากคลัง `lib/bank.js` (ไม่ซ้ำกับ 10 ทริปล่าสุด) แล้วให้ Groq (Qwen) แต่งคำพูดของนกพาไปถึงคำ/ประโยคนั้น + ตรวจแก้ภาษาอีกรอบ ผ่าน `/api/story`
- **ตรวจคำที่พูด:** Typhoon ASR (ถ้าล้มใช้ Groq Whisper) ผ่าน `/api/stt`
- **เสียงพากย์นก:** Gemini TTS (`gemini-3.8-flash-tts` เสียง Sulafat) ผ่าน `/api/tts` ถ้าไม่มีคีย์ใช้เสียงของเบราว์เซอร์
- **คีย์อยู่บนเซิร์ฟเวอร์เท่านั้น เบราว์เซอร์มองไม่เห็น** ถ้าไม่มีคีย์ เกมใช้เรื่องสำรอง 4 ทริป และตัวฟังคำพูดของเบราว์เซอร์แทน

```
public/index.html   เกม
api/story.js        ให้ Groq แต่งทริปใหม่ + ตรวจรูปแบบ/ภาษา/ไม่ซ้ำ ก่อนส่งให้เกม
api/stt.js          รับเสียง WAV → ส่งต่อให้ Typhoon / Groq
api/tts.js          ข้อความบทนก → เสียง WAV จาก Gemini TTS (แคชข้อความซ้ำ)
lib/bank.js         คลังคำ + ประโยคที่ให้ผู้เล่นพูด (นักอรรถบำบัดแก้ได้)
server.js           เซิร์ฟเวอร์ในเครื่อง (api/ ชุดเดียวกันใช้บน Vercel ได้เลย)
test/               ทดสอบ api/ โดยไม่เรียก API จริง
```
ถ้า Groq เลิกให้บริการรุ่นที่ใช้แต่งเรื่อง ตั้ง `GROQ_STORY_MODEL=ชื่อรุ่นใหม่` ใน `.env.local` ได้

## รันในเครื่อง (ต้องมี Node 22.9 ขึ้นไป)

**ง่ายสุด (Windows):** ดับเบิลคลิก `start.cmd` — ครั้งแรกจะเปิด Notepad ให้ใส่คีย์ แล้วเปิดเซิร์ฟเวอร์ + เบราว์เซอร์ให้เอง ปิดเซิร์ฟเวอร์ด้วยการปิดหน้าต่างดำ

หรือพิมพ์เอง:

```powershell
cd resona-web
Copy-Item .env.example .env.local
notepad .env.local          # ใส่ TYPHOON_API_KEY= GROQ_API_KEY= GEMINI_API_KEY= แล้วเซฟ (ไม่ต้องมี "")
npm.cmd start               # (Windows) เปิด http://localhost:8787 ใน Chrome หรือ Edge
```

ทดสอบโค้ดเซิร์ฟเวอร์: `npm test`

## ขึ้น Vercel

1. push โฟลเดอร์ `resona-web` ขึ้น GitHub (ไฟล์ `.env.local` ไม่ขึ้น เพราะอยู่ใน `.gitignore`)
2. ที่ vercel.com → Add New Project → เลือก repo → Framework Preset: **Other**
3. Settings → Environment Variables → ใส่ `TYPHOON_API_KEY`, `GROQ_API_KEY`, `GEMINI_API_KEY`
4. Deploy

## ข้อควรรู้

- **Gemini API:** ข้อตกลงของ Google กำหนดว่าเจ้าของคีย์ต้องอายุ 18 ปีขึ้นไป (ให้ครูที่ปรึกษา/ผู้ปกครองสมัคร) และแบบฟรี Google นำข้อความที่ส่งไปใช้พัฒนาระบบได้ — เราส่งเฉพาะบทของนก ไม่ส่งข้อมูลหรือเสียงผู้ป่วย

- เสียงที่อ่านคำ/ประโยคถูกส่งไปถอดคำที่ Typhoon / Groq (เกี่ยวกับ PDPA)
- `/api/stt` กันเว็บอื่นเรียกผ่านเบราว์เซอร์ แต่ยังไม่มี rate limit — ถ้าเปิดให้คนทั่วไปใช้จริง ควรเพิ่มการล็อกอินหรือจำกัดจำนวนครั้ง
